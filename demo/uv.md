# uv — шпаргалка для проекта probe

## Что это

**uv** — программа, которая управляет Python-проектом: ставит нужную версию Python, создаёт
для проекта отдельное окружение и устанавливает в него библиотеки. Она заменяет сразу
несколько привычных инструментов (`pip`, `venv`, `pyenv`) и работает очень быстро.

Аналогия: проект — это рецепт, uv — повар, который по рецепту закупает ровно те продукты
и в тех количествах, что указаны, и готовит на отдельной кухне, не трогая остальной дом.

## Зачем она в probe

Прибор обещает: **те же доказательства → те же числа**. Если бы версии библиотек
«плавали» (сегодня одна, через месяц другая), числа могли бы тихо измениться. uv
фиксирует точные версии всего, что установлено, и на любом компьютере воспроизводит
ровно их.

## Три файла, которые нужно знать

| Файл | Что в нём | Кто правит |
| --- | --- | --- |
| `pyproject.toml` | Какие библиотеки нужны проекту, в общих чертах («pydantic версии 2.9 или новее») | uv, командой `uv add` |
| `uv.lock` | Точные версии всего дерева библиотек («pydantic ровно 2.x.y») — замок | Только uv, руками не трогать |
| `.venv/` | Само окружение: установленный Python и библиотеки | uv; папку можно удалить, `uv sync` создаст заново |

`uv.lock` хранится в git вместе с кодом. Поэтому через год, на другом компьютере, сборка
окружения даст то же самое.

## Главная команда: `uv run`

```
uv run <команда>
```

Означает: «выполни эту команду внутри окружения проекта». Перед запуском uv сам
проверяет, что окружение соответствует замку, и при необходимости доустанавливает
недостающее. Активировать окружение вручную не нужно.

Примеры из проекта:

| Команда | Что делает |
| --- | --- |
| `uv run pytest` | Запускает все тесты |
| `uv run scripts/replay.py fixtures/personas/strong.json` | Печатает отчёт по сильному участнику (по эталонной разметке) |
| `uv run scripts/replay.py fixtures/personas/strong.json --observer model` | То же, но по разметке модели (записанный прогон) |
| `uv run scripts/sensitivity.py` | Таблица: как баллы зависят от параметра «пропущено» |
| `uv run --extra web streamlit run scripts/app.py` | Запускает интерфейс в браузере |

## Флаги, которые встречаются

| Флаг | Значение |
| --- | --- |
| `--extra web` | Подключить дополнительную группу библиотек `web` (Streamlit для интерфейса). Без него интерфейс не запустится: обычным тестам он не нужен, поэтому не ставится по умолчанию |
| `--offline` | Ни при каких условиях не выходить в интернет. **Для встречи без сети** |
| `--frozen` | Использовать замок как есть, ничего не пересчитывать. Так запускаются тесты в проверке после каждой правки |

## Остальные команды

| Команда | Когда нужна |
| --- | --- |
| `uv sync` | Привести окружение в точное соответствие замку. Первый запуск на новом компьютере или после `git pull` |
| `uv sync --extra web` | То же, вместе с библиотеками интерфейса |

**Осторожно:** `uv sync` без `--extra web` *удаляет* Streamlit — окружение приводится к
замку в точности. Без интернета вернуть его будет нельзя. Перед встречей используйте только
`uv sync --extra web`.
| `uv add <библиотека>` | Добавить библиотеку в проект: uv обновит `pyproject.toml` и `uv.lock`. Только так, не правкой файлов вручную |
| `uv add --optional web <библиотека>` | Добавить библиотеку в группу `web` (так добавлен Streamlit) |

## Если что-то пошло не так

- **`command not found: uv`** — uv не установлен. Установка (нужен интернет):
  `curl -LsSf https://astral.sh/uv/install.sh | sh`
- **Интерфейс не запускается, ошибка про `streamlit`** — забыт `--extra web`.
- **Без сети uv пытается что-то скачать** — добавьте `--offline`. Если и с ним ошибка,
  значит, нужного пакета нет в окружении: дома, с интернетом, выполните
  `uv sync --extra web` и повторите.
- **Остановить интерфейс** — в окне терминала нажать `Ctrl+C`.
- **Терминал после запуска молчит** — так и задумано: настройки в `.streamlit/config.toml`
  скрывают приветствие Streamlit (вместе с ним — его рекламное окно про «навыки для
  ИИ-агентов»). Браузер открывается сам; адрес — http://localhost:8501.

## Перед встречей без интернета

```
cd ~/probe
uv sync --extra web                                        # дома, с интернетом, один раз
uv run --offline --extra web streamlit run scripts/app.py  # проверка с выключенным Wi-Fi
```
